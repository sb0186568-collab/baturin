Что делают программы
1. normalize.py

Вводится строка; text.split() без аргумента режет её по любым пробельным символам и отбрасывает пустые части.

" ".join(...) собирает обратно через один пробел — так убираются пробелы по краям и лишние внутри.

Регистр сохраняется.

Выводятся: исходная длина, новая длина, нормализованный текст, число слов.

Слово здесь — непустая часть из split(); знаки препинания остаются частью слова.

2. palindrome.py

По правилам задания игнорируются регистр и обычные пробелы " ". Остальные символы (включая пунктуацию) сравниваются как есть.

text.lower() — приведение к нижнему регистру (исходная строка не меняется, т.к. str неизменяема).

.replace(" ", "") — удаление только обычных пробелов.

Проверка через срез cleaned == cleaned[::-1].

Если после очистки строка пуста → «Нет текста», иначе «Палиндром» / «Не палиндром».

3. replace.py

Сначала text.count(":") — считаем вхождения в исходном тексте.
Затем text.replace(":", "-") — получаем новую строку.
Важно делать замену после подсчёта: если сначала заменить, двоеточий уже не будет.
Выводятся количество замен и новая строка.

4. variant.py (вариант 8)

Вводится строка; text.split() даёт слова.

Для каждого слова word.strip(".,!?;:") убирает пунктуацию по краям, .lower() — нижний регистр.

Пустые после очистки слова пропускаются.

Условие отбора: cleaned.count("а") == 1.

Подходящие слова печатаются по одному на строке; в конце — общее количество.

Если подходящих слов нет — «Нет совпадений», количество 0.

Ключевые идеи
Строки неизменяемы. text.lower(), text.replace(...), text.strip(...) возвращают новую строку; исходная не меняется. Результат нужно присвоить или использовать сразу.

Слово ≠ подстрока. "армия".count("а") считает вхождения буквы, "ар" in "армия" проверяет наличие подстроки; split() выделяет именно слова, разделённые пробельными символами.

Правила обработки пунктуации задаются до кода. В задании 2 пунктуация сравнивается как есть, в варианте — удаляется с краёв. Если смешать правила, ответы будут другими.

Формируется новый список absolute: отрицательные заменяются на -number (модуль), остальные копируются как есть.

Если список пуст — «Нет данных».

Иначе определяется maximum = max(numbers), затем через enumerate() собираются все индексы, где значение равно максимуму. Порядок возрастает автоматически, т.к. обход идёт слева направо.

Отбираются числа, для которых 10 <= number <= 20.

Повторы сохраняются.

Если подходящих нет — [], 0, 0, [].

Ключевые идеи
append() vs items[i] = value. append добавляет новый элемент в конец (длина растёт), присваивание по индексу заменяет существующий (длина не меняется). Присваивание несуществующего индекса — ошибка.

sorted(items) vs items.sort(). sorted возвращает новый список, исходный не меняется. sort сортирует на месте и возвращает None — сохранять результат items = items.sort() нельзя.

Копия списка. copy = items — это два имени одного списка. Чтобы менять независимо, нужен items.copy() (в этой работе не требуется, т.к. мы строим новый список через append).

Исходный список во втором задании сохранён. Мы не делаем numbers[i] = abs(...), а формируем отдельный список absolute.

Что делают функции
sum_digits(number) — сумма цифр модуля. abs() нужен, чтобы отрицательное число приближалось к нулю при // 10. Для 0 возвращает 0 без входа в цикл.

average(numbers) — среднее списка или None при пустом списке. Исходный список не изменяется (используются sum и len).

normalize_text(text) — " ".join(text.lower().split()): нижний регистр, без пробелов по краям, один пробел между словами. Исходная строка не меняется (строки неизменяемы).

select_numbers(numbers, threshold) (вариант 8) — новый список чисел, для которых abs(number) <= threshold. Порядок и повторы сохраняются. Исходный список не изменяется.

Ключевые идеи
Возврат ≠ вывод. return отдаёт значение вызывающему коду; print() только показывает его человеку. Все функции здесь возвращают результат и не печатают.

Параметр ≠ локальная переменная. Параметр — имя в определении функции (значение приходит при вызове). Локальная переменная создаётся внутри и после return недоступна. global не нужен: данные приходят параметрами, результат уходит через return.

Чистые функции. functions.py не вызывает input()/print() — такой модуль можно импортировать и проверять через assert.

Проверки — не замена обработке ввода. assert подходит для учебных тестов, но при оптимизированном запуске (python -O) отключается, поэтому пользовательский ввод проверяют условиями и исключениями, а не assert.
